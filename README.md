# MD. Tahsin Ferdous - Portfolio

A macOS-style interactive personal portfolio showcasing my projects, skills, and experience.

## Features
- 🖥️ **macOS Interface**: A unique, interactive UI mimicking a macOS desktop.
- 🚀 **Projects & Skills**: Overview of my recent work, experience, and technical skills.

## Quick Start

To run this project locally:

```bash
npm install
npm run dev
```
